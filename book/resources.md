# 阅读与下载

当前版本是 **v0.1 · 第一阶段纵向切片**，开放导读与第 1—3 章。完整课程规划为 8 部分、28 章；其余正文逐步制作，尚未作为完整书籍出版。

## 在线阅读

[从导读开始](./00-导读.md)，或在[完整学习路线](./curriculum.md)中查看每一阶段要获得的能力。网页右上角可切换明暗主题、搜索已开放的教材全文。

阅读进度和练习勾选保存在当前浏览器中，不上传、不跨设备同步。清除浏览器数据会清除这些记录。标记完成代表你的自查，不能替代实际验收。

## 带走源码

所有教材人工编辑源稿位于 `book/*.md`。网站直接读取这份正文；案例代码位于 `cases/`；图解源文件位于 `assets/diagrams/`。你可以下载仓库后离线修改与运行。

- [查看完整 GitHub 仓库](https://github.com/liamamilin/codex-mastery)
- [下载 main 分支源码 ZIP](https://github.com/liamamilin/codex-mastery/archive/refs/heads/main.zip)
- [查看安装、开发与验证说明](https://github.com/liamamilin/codex-mastery#readme)
- [查看官方资料与术语](./附录-术语与来源.md)
