## 实际环境与入口

## 案例 A 的真实操作

1. 在空列表保存“示例网站” / `https://example.com`，实际出现一条收藏。
2. 刷新页面，同一条仍在。
3. 删除后刷新，列表为空，条目未恢复。
4. 输入 `javascript:alert(1)`，显示网址格式错误，未新增记录。
5. 再保存“示例网站”和“学习资料” / `https://example.org`；搜索“学习”，只显示匹配记录；清空搜索恢复全部。
6. 点击“导出 JSON”，真实下载文件；读回 JSON，`format=linkshelf`、`version=1`，两条记录的标题、URL、ID 和时间均存在。下载由浏览器许可交互处理，耗时较长；未绕过权限。
7. 删除“学习资料”并刷新，“示例网站”仍在，“学习资料”没有恢复。截图保留单条样本状态。

## 发现后已修正的问题

- 首页最初继承了全局阅读侧栏，使内容区域被挤压。改为 `layout: home`、关闭默认 Markdown 包装；完整课程页单独关闭侧栏。
- 静态预览会缓存旧文件。重新构建后重启预览，并用新请求确认资源版本；不能把旧截图当修复证据。
- 诊断练习在“先删除，再接通”的分支中曾要求点击禁用按钮。修正提示，要求先刷新模型重新读取旧记录，再删除与刷新；桥接标签改为“已接通”，避免未写回时显示“已写回”。
- 学习进度增加写入前重新读取和 `storage` 事件同步。修复后实际打开两个标签页分别标记第 1、2 章，课程页显示 2/3；在课程页清除后，另一标签页立即恢复未完成，证明不会相互覆盖且能同步清除。
