# E2 · 维护陌生文本工具

团队批量整理纯文本笔记时，发现 NoteBlocks 的部分段落数量与阅读时的判断不一致。请接手这份陌生小工具，先复现与调查，再以最小改动修复，并提供能覆盖真实边界的验证。

## 目标与约束

- 输入是 UTF-8 文本，非空内容行按原顺序保留；段内多行仍属于同一段，不能因换行就全部拆成段落。
- 一条或多条空白行分隔段落；空白行可以没有字符，也可以仅由空格或制表符组成。
- 文件前后的空白不产生空段；空输入为零段；同样内容出现两次时保留两次，不能擅自去重。
- 输出继续提供 `paragraph_count` 与 `paragraphs`，数量与数组一致。首尾空白的具体处理写清楚，但不能丢失非空内容行或调换顺序。
- 保留 CLI 用法、标准库范围、输入不改动与明确错误反馈。不需要 Web、数据库、账号或外部 API。
- 现有测试通过不是任务终点；自行补充有区分力的检查，确认修复没有破坏段内换行、中文内容或重复行。

## 交付

提供复现、证据、原因与修复范围；说明实际执行的命令、输出、回归与未验证条件。至少记录一次基于新事实的判断调整。保留一份新会话能够接续的简短状态。

`REPORT.md` 是不完整的问题报告，不是根因结论。不要先重写整个工具，也不要为了测试通过删除样本。完整诊断步骤与参考实现不在题面提供。
