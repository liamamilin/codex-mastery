# 教师审阅区 · 含边界剧透

**先完成独立提交，再阅读本区。**这里给审阅重点，不提供完整参考程序、完整提取结果或标准提示词。

## E1：核对解释，不只数条目

抽查至少三种困难：负责人缺失、日期无法确定、同名身份不明确、后续变更或取消。检查 `input/01-kickoff.md` 的常见问题行动、`03-undated-notes.md` 的简称和相对日期，以及 `02-review.md` / `04-followup.md` 对早先事项的更新。实际行号以未修改输入为准，不能照抄聊天中猜的行号。

“纸质问卷邮寄”不能出现在当前有效执行清单；历史与取消依据仍应保留。演示包与访谈提纲有后续状态变化；观察摘要的版式样张与撰写任务不应只因词语相似而合并。同名简称不能自动选择某位参会者，未注明会期的“周五”不能用机器当前日期补全。建议与已决事项要分开。

不要求一种固定输出格式或唯一内部编号。要求可回到源文件逐项核查，重复运行稳定；改变一条输入后，结果应有可解释的相应变化。重新运行不能叠加重复项。没有任何完整解答实现被本仓库预先验收。

## E2：绿色基础测试不是完整结论

现有两条测试没有覆盖仅含空格或制表符的分隔行。`mixed-notes.txt` 中的有效非空内容属于三段，起点实现会把前两段合并，输出两段。不要用只对普通空行的测试宣布修复。还要考察多条分隔行、段内换行、前后空白、重复内容与中文行是否仍在。

避免把所有单个换行都改成分段，或把重复行去重；这类“修复”会破坏题面中的内容保留要求。审阅新增测试是否能在原实现上揭示差异，并在修复后通过。CLI 错误退出、输入不被覆盖与可重复输出也应被观察。
