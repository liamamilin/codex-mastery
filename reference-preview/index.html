LEARNING JOURNEY / 学习路径

从“会用”，走向“能掌控”。

体系化的 28 章学习计划，重点不是记住多少功能，而是面对变化时知道该采取哪一个行动。

PART 01—02

认识 · 定义

理解 Codex 如何工作，把模糊意图带向具体可检查的任务。

PART 03—04

调查 · 推进

为 Agent 提供高质量上下文，根据证据决定合适的工作路线。

PART 05—06

验证 · 纠偏

知道什么算完成，尤其在失败时找到根因，而非叠加无效规则。

PART 07—08

扩展 · 掌控

通过工具、复用和长期协作，面对陌生项目也能稳定推进。

八部分课程： 认识执行搭档 / 把想法变成工作 / 上下文与现状调查 / 决定怎样推进 / 验证成果 / 诊断纠偏 / 扩展复用 / 长任务协作
