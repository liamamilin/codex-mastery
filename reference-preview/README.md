# Codex Mastery Lab｜视觉与交互方向样稿

直接用浏览器打开 `index.html`。这是**独立的无依赖静态演示页面**，用来告诉 Codex 书籍产品的审美方向与交互质感标准。

本样稿包含：

- 品牌与首屏视觉语言（深蓝、珊瑚橙、冷青，路径和证据节点隐喻）。
- 响应式布局和有层次的中文技术排版。
- 八部分 / 28 章 / 五类案例的课程规模展示（仅代表计划，不代表已完成）。
- 可真实操作且可重置的第 18 章诊断分支练习。
- 明确标注为**设计预览**，不是已经写好的教材，也不是运行案例的验证证据。

Codex 的正式实现需要从 `book/*.md` 读取真实文章，结合 `cases/` 中的真实示例、真实截图及配图。可延续本页设计，也可在相同品质目标下重新实现。不得把这一个静态页面当成项目最终交付。

## 随包制作时的检查记录

- 已检查 HTML 基本结构、锚点引用与内嵌 JavaScript 语法。
- 已通过简单的 JavaScript 事件逻辑模拟，覆盖 A/B 选择反馈、选中状态及重置行为。
- 制作环境中的 Chromium 对本地文件和 localhost 访问均返回管理员策略拦截；因此**本包未在真实浏览器完成视觉或点击验收**。请 Codex 在实际可访问的环境中，用 Playwright/浏览器验证桌面、手机排版和交互，并修复发现的问题。

## 正式发布方式

本页是本地视觉样稿，不是正式 Pages 网站。最终网站由 `book/*.md` + VitePress + Vue 构建，通过 GitHub Actions 发布到 GitHub Pages，详见 `14_GitHub_Pages_发布与部署.md`；不能直接上传本单页声称已完成 28 章。
