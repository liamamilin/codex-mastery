# CSV Insight 报告

从教材根目录定位 `cases/C-csv-insight/`。先读该案例 README 与实际脚本帮助，再确认用户要处理的输入和输出；技能本身所在目录不等于运行目录。

使用已有的 `report.py --input <CSV> --output <Markdown>`，在案例目录运行；macOS / Linux 用 `python3 -B`，Windows 已有 Python Launcher 时用 `py -3 -B`。用户另选输出时优先使用其路径；已有成果可能被覆盖时先保留需要的旧版本，不修改原始输入来凑结果。

案例字段为 `date,channel,visits,signups`。任一必需字段为空时排除整行，完全重复的有效行只计首条；日期、列数、数值格式或注册数大于访问数时拒绝整次生成，保留已有报告。以案例 README 和当前实现的准确口径为准。报告中保留实际排除数量和原因。改变口径前说明影响，不能把缺失值自动补成零或把访问、注册数解释成增长或因果效果。

用 `verify_totals.py` 的独立计算核对总访问、总注册与按渠道结果。相同输入与口径重复生成时比较实际输出，说明差异；不把脚本正常退出等同于数值已核对。检查失败时保留原始数据和错误，报告不一致处再调查，不发布未经核对的数值。

交付包含输入与口径、生成文件路径、关键汇总与独立核对结果、执行命令和仍未验证的范围。只进行本地文件处理；这个工作流不需要连接外部服务、安装全局技能或替用户发布报告。
